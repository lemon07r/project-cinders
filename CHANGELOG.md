# Changelog

Release notes in every supported language are at https://cinders.lr7.dev/en/changelog/.

## 0.3.1

Smoother updates.

- Press Install update once, then confirm in Android.
- After each step, focus moves to the next action.
- The What’s new card shows the new version and its notes.

## 0.3.0

First public release.

- English settings, an English quick panel over HDMI and a fast TV home for XGIMI projectors.
- Available in 10 languages.
- In-app updates: Project Cinders checks for a new version at most once a day and installs only when you confirm.
- 7-day free trial. Report a problem from System → Send feedback or report a problem.
